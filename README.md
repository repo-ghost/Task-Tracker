# Daylist

A simple, responsive task tracker built with HTML, CSS, and JavaScript. Tasks are saved in your browser's local storage, so they stay on the same browser and device between visits. There is no account or server-side sync.

Open `index.html` in a modern browser, or serve the folder with a static web server. On the first visit, a few starter tasks show how the app works; edit or delete them to make the list your own.

Add, edit, complete, search, sort, and delete tasks. Use the sidebar to filter by date, completion, or label. Press `/` to focus search.
